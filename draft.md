# Черновик: timelog

Статус: описание. Кода сервиса нет.

Публичный сервис логирования времени. Записи читают и пишут через HTTP API и MCP. Пользовательского интерфейса нет.

## Запись лога

Одна запись хранит:

- начало;
- конец;
- наименование;
- теги;
- комментарий.

## Доступ

Клиент ходит в API и MCP с приватным токеном. OAuth нет.

Один и тот же вид токена подходит и для API, и для MCP. Управление токенами в эти интерфейсы не входит.

Список токенов, создание и отзыв делаются командами внутри Docker-контейнера сервиса:

- посмотреть список токенов;
- создать токен;
- отозвать токен.

## Хранение

Сейчас данные лежат в PostgreSQL.

Позже можно добавить другие провайдеры хранения. Контракт API и MCP от выбора провайдера не зависит.
