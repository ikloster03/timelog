## ADDED Requirements

### Requirement: Инструменты журнала

MCP SHALL предоставлять операции того же журнала, что и HTTP:

- `start_log` создаёт запись с пустым концом; без начала берёт момент часов сервера
- `stop_log` записывает конец существующей записи по id; без конца берёт момент часов сервера
- `create_log` создаёт запись, в том числе сразу закрытую
- `update_log` меняет переданные поля записи по id, включая очистку конца
- `delete_log` удаляет запись по id
- `list_open_logs` возвращает записи с пустым концом
- `list_logs` возвращает записи с теми же фильтрами периода, открытости и тегов, что и список HTTP

Инструмент SHALL возвращать запись или список записей с теми же полями, что и HTTP. Нарушение правил журнала и неизвестный id SHALL возвращать ошибку инструмента, и журнал не меняется неверным вызовом.

#### Scenario: Начать дело

- **WHEN** клиент вызывает `start_log` с наименованием
- **THEN** в журнале появляется запись с пустым концом и этим наименованием

#### Scenario: Закончить одну из параллельных

- **WHEN** открыты две записи и клиент вызывает `stop_log` с id одной из них
- **THEN** конец появляется только у записи с этим id

#### Scenario: Тот же журнал, что у HTTP

- **WHEN** запись создана через `POST /logs` и клиент вызывает `list_open_logs`
- **THEN** инструмент возвращает эту запись, если её конец пуст

### Requirement: Тот же bearer-токен

Вызов MCP SHALL требовать тот же действующий bearer-токен, что и `/logs`. Запрос без токена, с неизвестным токеном или с отозванным токеном SHALL отклоняться до выполнения инструмента.

#### Scenario: Без токена

- **WHEN** клиент вызывает `list_open_logs` без токена
- **THEN** система отклоняет вызов и не возвращает записи

#### Scenario: Отозванный токен

- **WHEN** клиент вызывает `start_log` с отозванным токеном
- **THEN** система отклоняет вызов и не создаёт запись

### Requirement: MCP не управляет токенами

Среди инструментов MCP SHALL NOT быть выпуска, списка и отзыва токенов.

#### Scenario: Нет инструмента выпуска

- **WHEN** клиент запрашивает список инструментов MCP
- **THEN** в списке есть инструменты журнала и нет инструмента создания токена
